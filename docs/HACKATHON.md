# Hackathon checklist and credit offers
Reference: [official participant guide](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details), reviewed Oct 27, 2026 (America/Chicago).

## Submission
Public repository required; maximum four participants; incorporate Meta models. Only features/code built during the event may be presented as original hackathon work. Attribute upstream code and assets.
Submission requires a three-minute demo video. Current deadline: Nov 4, 2026 at 9 PM Eastern (8 PM Central). Recheck the live guide for changes.

## Credits
- Meta Model API: advertised $150 participant credit. Confirm activation and account balance in the private billing dashboard.
- Baseten: request $100 and 2M TPM; up to 2,000 approved participants, selected by use case, individual grants. Form says no Baseten signup is needed before applying. For the event the guide specifies meta-models/muse-spark-open-1026.
- Modal: request $100; live application says up to 1,000 selected teams, not first-come-first-served (different wording from guide). Requires an actual Modal workspace and account email.
- Fireworks: request $25 per selected team; shortlisted teams receive redemption details by email.

Partner grants are discretionary, not guaranteed. Application submission is not proof of a credited balance. Keep account details, redemption links, API keys, and application receipts private.
Review redemption expiry, permitted models, usage limits, data terms, and overage behavior when grants arrive. Do not add payment details or authorize charges as part of a credit request. Spending notifications may not be hard limits.
